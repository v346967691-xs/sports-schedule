# NBA 队名全局简化

30 支 NBA 球队统一显示队名，如湖人、勇士、凯尔特人、76人，不再带城市。统一映射位于 `utils/nba-names.js`，同步脚本复用同一份映射。

覆盖赛程卡片、球队详情、球队关注、我的关注比赛、积分榜、球员所属队、比赛详情、搜索、日报、分享图和订阅提醒文案。客户端读取旧云端数据及旧关注记录时也会转换，不必等待后端数据重抓。原 ID、缩写、英文原名和关注身份保留；搜索兼容城市全名。

没有新增请求、定时任务、数据表或刷新频率，额度消耗策略不变。当前测试 319 项通过，冒烟检查 718 项通过。

发布目录仍为 `D:/work/wbzone/_verify`。本次完成后以此目录发布小程序即可，无需 WB 执行 SQL 或额外部署任务。后端同步任务随仓库代码正常更新使用新映射。未执行微信上传或真机发布。
