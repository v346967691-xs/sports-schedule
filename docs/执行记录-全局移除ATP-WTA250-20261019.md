## 覆盖范围

- `utils/tennis-scope.js` 为统一过滤规则，按 ATP/WTA、赛事等级、赛事名/城市别名和届次日期识别，不按选手排名或冠军积分数判断赛事等级。
- 主同步在抓取对阵前排除 250；保留旧快照、补录行也过滤。正式周榜/等级周历的既有读取前移，没有新增来源请求。
- 实时比分扫描在记录开赛时间、判断活跃比赛前过滤，公共活动探针复用该路径；250 不再驱动盯场和闲时唤醒。旧班次运行中的进程使用旧代码，新班次检出新 master 后启用新规则。
- 单场统计在读统计桶、调用逐场来源之前排除；已结束的缺项重试也不会再覆盖 250。
- 赛程、首页、整站归档、选手比赛记录、旧详情深链接及参赛前景均排除。客户端即使拿到旧包内或云端快照，也使用相同规则过滤。
- 巡回赛等级周历作为识别元数据保留。实时积分任务把最新等级周历同步到 GitHub 本地既有排名文件，供随后统计和盯场读取；报名名单和参赛前景不再采集/列出 250。
- 选手正式排名、实时总积分和年度积分仍按来源完整总数显示，不能自行扣掉选手在 250 赛事获得的积分。
