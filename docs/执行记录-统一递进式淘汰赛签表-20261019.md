# 执行记录：统一递进式淘汰赛签表
日期：2026-10-19

## 本次已实现
网球分站、S赛专区、赛程页的已有递进式单败淘汰赛签表，共用双轮横滑、轮次图标、决赛奖杯、缩放与自动适配组件。支持128强至决赛的明确轮次；点击对阵保持原详情入口。
只根据已确认的晋级关系连线，缺失轮次时不跨轮猜测。数据只写“淘汰赛”、缺少明确轮次或关系的比赛保留赛程列表，不能据日期制造签表。
本次不增加后台采集请求或刷新频率；原瑞士轮入口、250赛事移除及直播改动保留。

## 已确定、待后续实现的特殊赛制
用户已选定双败淘汰赛使用“胜者组／败者组／总决赛”页签，并标明落入败者组的来源。该部分属于本轮讨论确认，尚未开发，需按当届赛事规则和可获得的晋级关系接入。
其他讨论建议：小组循环用积分榜与出线线；联赛阶段—附加赛—淘汰赛用阶段页签；特殊附加赛用晋级路径；季军／排位赛独立展示。
两回合及BO系列赛可沿用单败拓扑，但需要汇总卡片适配：两回合总比分与各回合、系列赛局分与各小局分别展示；不宣称本次已补齐所有赛事的这些来源数据。
