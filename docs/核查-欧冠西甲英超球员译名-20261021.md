# 欧冠、西甲、英超球员译名核查（2026-10-21）

## 结果与范围

一次性读取ESPN三项赛事球队列表与名册，按球队/球员ID去重，共66支球队、2037名在册球员；包含扩展名册和青年球员，不等于各赛事正式报名人数。原字典可匹配1050人；本次人工补75人，另纠正6处既有译名。仍未核实的912人保留英文，不宣称全量中文化。

重点补齐马奎尔、什琴斯尼、阿什拉夫·哈基米、塞斯科、孔萨、乔·戈麦斯、埃斯特旺、久保建英等；纠正德利赫特、巴尔科拉、埃泽、赫伊森、哈维·埃斯帕特，以及青年球员塞尔希奥·马丁内斯被误套另一球员全名的情况。

## 实现与维护

- 人工权威层仍为 `tools/zh-names.js`，足球自动种子仍为 `tools/player-zh.js`，本次未重新运行批量Wikidata播种。
- `node tools/build-football-player-names.js` 在本地合并两层生成 `data/football-player-names.js`，人工覆盖自动；排除NBA字典ID。生成器不访问网络。`--check` 可校验是否同步。
- 原播种器成功写入时也重新生成客户端表；测试校验客户端与源表完全一致，防止只补采集脚本、旧客户端却仍显示英文。
- `utils/football-players.js` 仅对 `ucl`、`liga`、`epl` 按ID修正旧首发/替补阵容、球队名册、射手/助攻榜及MVP候选。英文全名与短名保留在名册用于身份/搜索；比分、技术统计、球衣号码、候选人ID不变。
- 不按缩写、姓氏、球衣号或球队归属猜人。同姓如费兰·托雷斯与保·托雷斯仍按ID区分。没有ID或无可靠译名的旧记录保留原文。
- 字典和结果在内存复用，没有新增轮询、云函数、数据表或经常性请求，也没有强制重抓所有历史详情。名册请求仅为本次核查的一次性只读工作。
